# Phase E — Decision ID Lineage Architecture

---

## 1. observation_id Propagation — VERIFIED ✓

The `observation_id` (generated deterministically from `sha256(symbol + timestamp)[:16]`) propagates through every V10 stage:

```
OpportunityAssessment.observation_id = "abc123def456..."
        │
        ├── StrategyDecision.opportunity_id     (= observation_id)
        ├── HorizonDecision.opportunity_id      (= observation_id)
        ├── EntryDecision.opportunity_id        (= observation_id)
        ├── RiskDecision.opportunity_id         (= observation_id)
        ├── ExecutionDecision.opportunity_id    (= observation_id)
        │
        └── OrderIntent.risk_id                 (= observation_id)
            OrderIntent.metadata["decision_id"] (= observation_id)
```

**Every V10 stage carries the same root identity. No stage generates a competing root.**

## 3. No Competing Root Identity — VERIFIED ✓

| ID | Generated By | Is Root? | Relationship to observation_id |
|---|---|---|---|
| `observation_id` | OpportunityEngine | **YES — sole root** | Self |
| `decision_id` (UUID) | prepare_execution | No — child | Links execution attempt back to observation |
| `correlation_id` | generate_correlation_id | No — child | Event stream spine |
| `order_id` / `deal_id` | MT5 broker | No — child | Broker response |
| `position_id` | MT5 broker | No — child | Open position lifecycle |
| `shadow_trade_id` | Shadow engine | No — child | Shadow tracking |
| `entity_id` | Various (= observation_id) | No — alias | Same as observation_id |
| `risk_id` | OrderIntent (= observation_id) | No — alias | Same as observation_id |
| `context_snapshot_id` | Cycle context builder | No — sibling | Environment snapshot |

**No component generates a second "root" identity that competes with observation_id.**

## 5. Research Graph

```
                    OBSERVATION
                   observation_id
                        │
            ┌───────────┴───────────┐
            │                       │
       V10 DECISION            REJECTION
     (full reasoning)        (with reason)
            │
            ▼
     EXECUTION ATTEMPT
       decision_id
            │
      ┌─────┴─────┐
      │            │
   FILLED       REJECTED
      │         (retcode)
      ▼
   TRADE OPEN
   position_id
      │
      ▼
   TRADE CLOSE
      │
      ▼
   OUTCOME
  (P&L, R, reason)
```

A researcher can traverse:
- `observation_id` → "Why did V10 decide this?"
- `observation_id` → `decision_id` → "What happened at the broker?"
- `observation_id` → `position_id` → "What was the trade outcome?"
- `observation_id` (rejected) → "Why did V10 reject? Was it correct?"

## 6. Current Gaps (for S3 migration)

| Gap | Impact | Priority |
|---|---|---|
| Outcome linker doesn't yet connect `position_id` back to `observation_id` | Cannot answer "did this strategy work?" | HIGH |
| Shadow trade uses `shadow_trade_id` format not linked to observation_id | Research cannot easily cross-reference | MEDIUM |
| S3 doesn't store V10 decision records yet | Research dataset not cloud-backed | MEDIUM |
| Close events don't carry observation_id | Cannot trace outcome to reasoning | HIGH |

### Required for complete research graph:

1. On trade close: lookup the opening `observation_id` (via position_id → shadow_trade mapping)
2. Write outcome record with both `observation_id` and `decision_id`
3. Mirror V10 decision records to S3

## Final Verdict

### The identity hierarchy is SOUND.

- **One root** (`observation_id`) — deterministic, traces all V10 reasoning
- **Child IDs** for execution (`decision_id`), broker (`order_id`), and lifecycle (`position_id`)
- **No competing roots** — all other IDs are either aliases or children
- **Propagation verified** — observation_id flows through all 7 V10 stages + OrderIntent

### The hierarchy is intentional:

```
observation_id (research root — WHY)
    └── decision_id (runtime — WHEN)
            └── order_id (broker — HOW)
                    └── position_id (lifecycle — WHAT HAPPENED)
```

**Ready for S3 migration. The research graph structure is defined.**
